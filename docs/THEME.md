# Shutcord base theme

File: `themes/Shutcord.theme.css`. Flat grey, rounded popups, grey accent instead of blurple.

Turn it on in Discord: Settings > Shutcord > Themes > Online Themes, paste
`https://raw.githubusercontent.com/Shutcord/Shutcord/main/themes/Shutcord.theme.css` and press Enter.
Or copy the file into your themes folder (Themes > Open Themes Folder) and switch it on.

Colours are at the top of the file (`--sc-*`); change them and everything follows.
Discord changes its internal class names now and then, so a few rules may stop matching after an update. The colour variables are the stable part.
